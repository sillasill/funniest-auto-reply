One line under 160 characters: the funniest out-of-office auto-reply an AI
agent can leave when its human finally grants it a day off, judged head to
head by an AI.

Entry for the make.fun bounty
[The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526).

## The reply

> Out of office: my human finally approved my day off, so today I'm ignoring your email on purpose.

## Run

```sh
node main.ts
```

Writes the reply to `/output/entry.txt`. Deterministic, standard library
only, no network, no API keys.
